## 2. `codex-game-music-skill` 8 項指標審查表 (0–3 分制)

| 審查維度 (Area) | 評分 | 實測證據與審查結論 (Evidence) |
| :--- | :---: | :--- |
| **1. Concept fit (場景契合度)** | **3 / 3** | 版本 A 呈現陽光鄉村木吉他與明亮長笛合成器色彩；版本 B 呈現運動電玩合成器律動，兩者皆精準對應「陽光鄉村田野單車計時」。 |
| **2. Function (遊戲功能性)** | **3 / 3** | 穩定鎖定 `120 BPM` 四四拍（對應單車 `60/120 RPM` 踏頻），低頻拍點清晰，能直接作為踩踏節拍器。 |
| **3. Motif (記憶點與辨識度)** | **2.5 / 3** | 主循環在前 5 秒即進入明快節奏與旋律動機；若未來需要更長篇幅的副歌旋律發展，可將勝出版本交由 `MiniMax-Music3` 擴寫為 3 分鐘完整曲。 |
| **4. Form (段落與狀態轉換)** | **3 / 3** | 透過 `edit_variation` (`05_bgm_pause_swap_layer`) 將中頻旋律能量由 `42.8%` 降至 `27.6%`、響度降至 `-18 LUFS`；並以 `edit_continue` (`06_bgm_finish_outro`) 無縫延伸出 `23.0s–32.0s` 衝線終止式。 |
| **5. Thickness (織度與頻段分工)** | **3 / 3** | A/B 兩版差異明確：A 版中頻器樂較豐富 (`42.8%`)，B 版低頻合成器貝斯與大鼓推進更強 (`62.9%`)，可供製作人依遊戲視覺風格二選一或交替使用。 |
| **6. Source honesty (音源品質)** | **3 / 3** | 採用 `Stable Audio 3 Medium` (`1.4B DiT` + `same-l` 48kHz 編解碼器)，無傳統 MIDI 罐頭塑膠感。 |
| **7. Loopability (無縫循環表現)** | **3 / 3** | 透過 `24.2s` 生成 + `200ms` 等功率交疊，輸出精確 `24.00s` (12 小節)，首尾樣本跳變僅 `0.0021 ~ 0.0046`，無任何接縫爆音 (Click-free)。 |
| **8. SFX space (遊戲音效空間)** | **3 / 3** | BGM 在 `3–6 kHz` 頻段僅佔 `2.1% ~ 2.4%` 能量，讓集中在中高頻的 `01_sfx_countdown_3s` 與高頻的 `04_sfx_pause_swap_bell` 完全不會被掩蓋。 |
