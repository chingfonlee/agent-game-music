## 4. 驗證發現的問題（需修正）

1. **`qa_report.passed` 永遠是 True**：修復後仍未達標也會標示通過，與實際品質不符。
2. **Outro 中頻門檻不適用重金屬**：`min_climax_mid_pct: 20%` 是絕對值，但本曲全曲中頻能量僅約 9–13%（低頻主導），所以每次必定失敗 → 兩次重試都無效 → 最後套用「重複第 9–12 小節 + 淡出」權宜修補。衝線段最終中頻 12–14%，**實際上並未達標**。
3. **Outro 沒有套用 SFX 頻段保護**：最終 3–6 kHz 佔比 8.2%（超過 8% 上限，只有 Loop 角色會檢查）。
4. **對齊搜尋範圍太窄**：Loop B 的接縫窗 Chroma 只有 0.516，±160 ms 的微調無法修正和聲不連續。
5. **指標命名混淆**：`post_info.loop_chroma_similarity`（200 ms 接縫窗）和 `final_diagnostics.loop_chroma_similarity`（2 s 小節窗）同名，意義卻不同。
